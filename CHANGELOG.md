# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [Unreleased]

### Added

- NanoGPT node with full API coverage: chat, text generation, image generation, video generation, speech-to-text, text-to-speech, embeddings, web scraping, web search, models, context memory, TEE verification, balance & subscription, and Nano crypto operations
- Dynamic model loading via API for text, image, video, embedding, TTS, and STT models
- OpenAI-compatible chat completions with web search, prompt caching, reasoning, and memory
- OpenAI Responses API support
- Anthropic-compatible Messages API support
- Image-to-image, inpainting, and LoRA support
- NanoGPT API credentials with multiple base URL options
